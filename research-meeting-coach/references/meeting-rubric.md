# Meeting Quality Rubric

This is a draft ordinal rubric for evaluation and human calibration. Do not present a weighted total or validated score unless human review data establish it.

Score each dimension from 0 to 4:

| Dimension | 0 | 2 | 4 |
|---|---|---|---|
| Core problem clarity | research topic remains unclear | topic is visible but state change is vague | question and current state change are clear quickly |
| Evidence sufficiency | claims lack supplied evidence | evidence exists but mapping is unclear | consequential claims map to minimal traceable evidence |
| Reasoning boundary | speculation is written as fact | some hedging exists | observation, interpretation, hypothesis, and proposal are distinct |
| Uncertainty quality | uncertainty is hidden or generic | blocker is named | alternatives and discriminating evidence are clear |
| Decision usability | no answerable ask | broad question | advisor can choose, prioritize, or request a specific test |
| Continuity | prior requests disappear | some actions are tracked | all supplied actions and changes are traceable |
| Information efficiency | activity and background dominate | mostly focused | main path contains only understanding, evaluation, or decision value |
| Advisor fit | unsupported generic personalization | tentative evidence is used cautiously | ordering and depth follow traceable behavioral evidence |
| Student learning | output is unexplained | some rationale appears | the student receives repeatable reasoning cues without false performance claims |

For comparisons, show dimension-level results and evidence. Human blind preference and correction burden are stronger product evidence than an LLM self-score.
