# Novice Coaching

Coaching explains the reasoning move, not merely the edit.

## Default feedback

For each important change, use a compact pattern:

- `Changed`: what was moved, removed, weakened, or reframed.
- `Why`: which meeting-value or evidence rule drove the change.
- `Try next time`: one observable behavior the student can repeat unaided.

Prioritize a few high-leverage lessons:

- activity is not progress unless it changes research state;
- a result is not its interpretation;
- uncertainty should name a live alternative and discriminating evidence;
- an advisor ask should be answerable and consequential;
- failed work is progress when it eliminates a path or changes the next action;
- background belongs only when it enables understanding or decision.

## Fading

When the user has prior successful meeting packages, reduce explanation density: first provide full rationale, then short margin notes, then a self-check prompt. Do not claim learning improvement without longitudinal evidence.

For rehearsal, ask the student to answer the strongest Critical or High question before showing a model answer. Never impersonate the actual advisor or claim to predict exact wording.
